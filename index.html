To export from your Google Sheet companion:

  1. Open your BG3 Companion Google Sheet
  2. Go to Extensions → Apps Script
  3. Add the function below to BG3_Companion_Core.gs
  4. Run exportSpellJSON — the JSON logs to the console
  5. Copy it from the Execution Log and paste it in the JSON tab
The exported JSON has shape: {"spells":[...],"chars":["Gale","Tav"],"charInfo":{"Gale":{"cls":"Wizard","sub":"","race":"Human"}}}
